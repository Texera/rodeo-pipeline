Works with Claude Desktop, Claude Code, Cursor and any other MCP client.

  1. Open your client's MCP configuration
    Claude Desktop keeps it in claude_desktop_config.json; Claude Code uses .mcp.json. Most other clients use the same shape.
  2. Paste this in 
    {{ displayedConfigSnippet }}
  3. Your account token

    This is already inside the configuration above. It identifies you, so treat it like a password — anyone holding it can act as you until it expires.

    {{ tokenRevealed ? token : maskedToken }}
  4. Restart the client and check it worked
    Ask it: “call texera_whoami”. It should answer with your account name and this deployment. If it does, everything else will work too.
